This is an Astro Starlight documentation site for creating the 'Randy AI Docs' platform. Randy is a JARVIS-like assistant with Randy Marsh personality that helps with MCP (Model Context Protocol) documentation and interaction.

Key commands:
- pnpm dev: Start development server  
- pnpm build: Build for production
- pnpm preview: Preview built site

The project will feature:
- Interactive Randy assistant component
- MCP server connection playground
- Runnable code examples in docs
- Integration with pocket-pick test server
- Go and JavaScript MCP examples

Project structure:
- /workdir/src/content/docs/ - Documentation pages
- /workdir/src/components/ - React/Astro components  
- /workdir/src/assets/ - Static assets
- /workdir/package.json - Dependencies
