## Advanced Features

### Real-time MCP Tool Execution

When connected to an MCP server, Randy can:

```typescript
// Example tool calls Randy can make
await mcpServer.callTool('search_items', {
  query: 'your search term',
  limit: 10
});

await mcpServer.callTool('add_item', {
  text: 'new item content',
  tags: ['tag1', 'tag2']
});
```

### Dynamic Server Discovery

Randy automatically discovers available tools and capabilities:

- **Tool Enumeration**: Lists all available server tools
- **Capability Detection**: Identifies read/write/search permissions
- **Version Checking**: Ensures compatibility
- **Error Handling**: Provides helpful error messages

### Interactive Code Examples

Randy can generate and explain code snippets:

**Go MCP Server Example:**
```go
package main

import (
    "github.com/mark3labs/mcp-go/mcp"
    "github.com/mark3labs/mcp-go/server"
)

func main() {
    s := server.NewStdioServer("my-server", "1.0.0")
    // Randy can help you build this!
}
```

**JavaScript MCP Server Example:**
```javascript
import { StdioServerTransport } from '@openai/mcp-server';

const server = new StdioServerTransport({
  name: 'my-server',
  version: '1.0.0'
});
// Randy explains each step!
```

## Playground Controls

### Clear & Reset
- **Clear Chat**: Removes conversation history
- **Reset Randy**: Restarts Randy's personality engine
- **Disconnect**: Closes MCP server connections

Randy automatically detects your intent, but you can explicitly request:
- **"Switch to chat mode"** - Casual conversation
- **"I need help building something"** - Request-response mode
