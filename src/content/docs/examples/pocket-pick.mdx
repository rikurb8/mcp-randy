Experience Randy connecting to a real MCP server! This demonstration uses the [pocket-pick](https://github.com/disler/pocket-pick) server, which provides a personal knowledge base with MCP interface.

## 🎯 What is Pocket-Pick?

Pocket-pick is a real-world MCP server that demonstrates:
- **Personal Knowledge Management**: Store and retrieve text snippets
- **Tag-based Organization**: Categorize items with tags
- **Search Capabilities**: Full-text search across stored items
- **SQLite Backend**: Persistent data storage
- **MCP Protocol**: Full protocol compliance

## Real Server Setup

To run your own pocket-pick server for this demo:

### Installation

```bash
# Clone the repository
git clone https://github.com/disler/pocket-pick.git
cd pocket-pick

# Install dependencies (requires uv)
uv pip install -e .

# Initialize the database
pocket-pick init

# Start the MCP server
pocket-pick mcp-server
```

### Server Configuration

```json
{
  "name": "pocket-pick",
  "version": "1.0.0",
  "description": "Personal knowledge base with MCP interface",
  "tools": [
    {
      "name": "search_items",
      "description": "Search for items by text content",
      "parameters": {
        "query": "string",
        "limit": "number (optional)"
      }
    },
    {
      "name": "add_item", 
      "description": "Add a new item to the knowledge base",
      "parameters": {
        "text": "string (required)",
        "tags": "array of strings (optional)"
      }
    },
    {
      "name": "get_item_by_id",
      "description": "Retrieve a specific item by its ID",
      "parameters": {
        "id": "number (required)"
      }
    },
    {
      "name": "list_tags",
      "description": "Get all available tags",
      "parameters": {}
    }
  ]
}
```

## Database Structure

Pocket-pick uses SQLite with this schema:

```sql
CREATE TABLE items (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    created TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    text TEXT NOT NULL,
    tags TEXT  -- JSON array of tag strings
);

-- Example data
INSERT INTO items (text, tags) VALUES 
('MCP protocol enables AI agents to interact with external tools', '["mcp", "ai", "protocol"]'),
('JavaScript MCP servers can be built with OpenAI agents SDK', '["javascript", "mcp", "sdk"]'),
('Go implementation provides type safety for MCP development', '["go", "mcp", "types"]');
```

## SQLite Export & Analysis

### Data Export

Randy can help you export and analyze the pocket-pick database:

```python
# Export script Randy can generate
import sqlite3
import json
from datetime import datetime

def export_pocket_pick_data(db_path='pocket_pick.db'):
    conn = sqlite3.connect(db_path)
    cursor = conn.cursor()
    
    # Export all items
    cursor.execute("SELECT * FROM items")
    items = cursor.fetchall()
    
    export_data = {
        'exported_at': datetime.now().isoformat(),
        'total_items': len(items),
        'items': [
            {
                'id': item[0],
                'created': item[1], 
                'text': item[2],
                'tags': json.loads(item[3]) if item[3] else []
            }
            for item in items
        ]
    }
    
    return export_data

# Randy can run this and show you the results!
```

### Validation & Evaluation

Randy can validate the MCP server implementation:

```python
# Validation script Randy uses
async def validate_mcp_server(server_url):
    tests = [
        ('search_items', {'query': 'test'}),
        ('list_tags', {}),
        ('add_item', {'text': 'test item', 'tags': ['test']}),
        ('get_item_by_id', {'id': 1})
    ]
    
    results = []
    for tool_name, params in tests:
        try:
            result = await call_mcp_tool(server_url, tool_name, params)
            results.append({
                'tool': tool_name,
                'status': 'success',
                'response': result
            })
        except Exception as e:
            results.append({
                'tool': tool_name, 
                'status': 'error',
                'error': str(e)
            })
    
    return results
```
